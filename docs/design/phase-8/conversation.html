What happens when a customer cancels an order after it has shipped?
High confidence Turn 1

The order can't be cancelled once it has shipped. Instead, the customer starts a return, and the refund is issued when the warehouse confirms the item is back . The return window is 30 days from delivery .

Does the refund go back to the original card?
Medium confidence Turn 2
A source has changed since this answer was written. G2 was updated after it was read.

Yes. Refunds go back to the payment method used for the order . If that card has expired, the code falls back to store credit .

What I'm not sure about The documentation doesn't say whether customers are told about the store-credit fallback.
